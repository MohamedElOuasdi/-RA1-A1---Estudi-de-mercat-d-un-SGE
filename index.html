1. Introducció

Un Sistema de Gestió Empresarial (SGE) és un programari que integra i automatitza els processos d'una organització (finances, compres, producció, magatzem, recursos humans, clients...) en una única plataforma amb una base de dades comuna. Els tipus principals són els ERP (planificació de recursos empresarials), els CRM (relació amb clients) i les eines de BI (anàlisi de dades).

Hem triat IFS Cloud, un ERP modern especialitzat en empreses "intensives en actius": manufactura, aeroespacial i defensa, energia, construcció i serveis de camp. Inclou també funcionalitats d'EAM, FSM i IA, per la qual cosa s'acosta a una plataforma completa més que a un ERP clàssic.

Desenvolupador
IFS AB (Industrial and Financial Systems), Linköping, Suècia
Primera versió
Empresa fundada el 1983; IFS Applications als anys 90; IFS Cloud presentat el 2020 (primera release numerada 21R1)
Versió estable
26R1 (maig 2026). Cicle de dues releases a l'any: R1 (primavera) i R2 (tardor)
Llenguatges
PL/SQL (lògica de negoci), Java (capa intermèdia), JavaScript/TypeScript (client web) i models propis d'IFS
Plataformes
Client: qualsevol navegador (Chrome, Edge, Firefox, Safari) i apps mòbils iOS/Android. Servidor: contenidors Linux sobre Kubernetes
Sector
ERP + EAM + FSM + IA (IFS.ai)

Història cronològica

1983 – Es funda IFS a Linköping (Suècia).
Anys 90 – Naix IFS Applications (arquitectura client-servidor sobre Oracle).
2000-2018 – Versions 2003, 7.5, 8, 9 i 10; IFS es consolida en manufactura i manteniment.
2020-2021 – Es presenta IFS Cloud: arquitectura web, contenidors i releases semestrals (21R1, 21R2...).
2023-2025 – Arriba IFS.ai (IA integrada) i solucions de sostenibilitat (ESG).
2026 – Release 26R1 (maig), amb IFS Zero per a la gestió d'emissions.

Arquitectura

IFS Cloud segueix una arquitectura multicapa amb serveis exposats via REST/OData (les "projections"), desplegada en contenidors Docker sobre Kubernetes.

3. Tipus de llicències i preus

  • Llicència: comercial i privativa (no és programari lliure).
  • Modalitats de distribució: Cloud (SaaS gestionat per IFS), Remote (IFS opera l'entorn del client) i Managed/On-Premise (el client l'executa amb la seva infraestructura o núvol).
  • Subscripció: per usuaris (nominals o concurrents) i per mòduls/rol. Els preus no són públics: es fan a mida per pressupost segons usuaris, mòduls i desplegament. Normalment hi ha també costos d'implantació amb un partner.

4. Sistemes gestors de bases de dades

  • El SGBD és relacional: Oracle Database, on resideix gran part de la lògica de negoci en PL/SQL.
  • S'hi afegeixen serveis per a analítica (en memòria) i integració via APIs OData/REST.
  • Requereix llicències d'Oracle en desplegaments propis; en modalitat Cloud les gestiona IFS.

5. Instal·lació i accés al sistema

  • Instal·ladors: paquets/imatges de contenidor i eines de desplegament (Helm/Kubernetes) per a entorns propis; en Cloud no cal instal·lar res.
  • Contractació: demanar una demo a IFS o a un partner → pressupost → projecte d'implantació (anàlisi, configuració, migració de dades, formació, go-live).
  • Accés: client web (Aurena) des del navegador, aplicacions mòbils (p. ex. per a tècnics de camp) i integracions per API.

6. Mòduls i funcionalitats

EAM – Enterprise Asset Management
Manteniment preventiu i correctiu, ordres de treball, gestió d'actius i previsió d'avaries amb IA.
Manufactura i cadena de subministrament
Planificació de producció (MRP), BOM, rutes, ordres de fabricació, magatzem, compres i inventari.
Field Service Management (FSM)
Planificació de tècnics, optimització de rutes, contractes de servei i app mòbil.

Altres mòduls: Finances, Projectes, HCM (RH) i Sostenibilitat (IFS Zero).

Crear nous mòduls i extensions

IFS Cloud permet configurar (camps personalitzats, pàgines, esdeveniments) i estendre el sistema amb codi. Llenguatges: PL/SQL, models declaratius d'IFS (entity, projection, client) i Java/APIs REST per a integracions. L'eina de desenvolupament habitual és IFS Developer Studio (basat en Visual Studio Code) i clients SQL com SQL Developer.

-- Exemple simplificat de funció PL/SQL
FUNCTION Get_Discount (customer_id_ IN VARCHAR2) RETURN NUMBER IS
   discount_ NUMBER := 0;
BEGIN
   SELECT discount INTO discount_
   FROM customer_tab WHERE customer_id = customer_id_;
   RETURN discount_;
END Get_Discount;
